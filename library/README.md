# library/

**Third-party content only.** Newsletters, podcasts, videos, articles, social
posts — anything produced by someone else.

Kept strictly separate from `brand/`. See `brand/README.md` for why that matters
more than it sounds like it does.

```
library/
  newsletters/
  podcasts/
  videos/
  social/
  articles/
```

## Front matter

Required, and it must carry the real source: `author`, `url`, `date`, and where
you found it. An entry here without attribution is worse than no entry, because
it will eventually get quoted as though it were yours.
